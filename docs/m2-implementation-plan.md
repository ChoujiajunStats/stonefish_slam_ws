## 源码审计发现

锁定 Stonefish IMU 实现输出运动加速度，缺少重力扣除及传感器偏置位置的
向心项。它不能直接作为 VIO 的比力输入。原接口留给 M0/M1，M2 通过显式
opt-in 补丁生成物理意义明确的比力，不把真值姿态送给估计器。

原相机消息在 GPU 回读时打当前时间戳，且非连续相机轮流渲染，不能作为同步
双目采样证据。M2 需要共同渲染快照、随图像缓冲保存的采样时间，处理层只配对
同一真实采样时刻的图像，不重打时间戳制造同步。

原空水域无可靠视觉特征。新增明确命名的视觉诊断场景；保留空水域作为退化
测试，不把人工纹理场景的结果泛化成任意水下环境通过。
