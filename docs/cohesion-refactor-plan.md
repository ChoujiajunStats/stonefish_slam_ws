# 2026-09-29 职责边界重构

本轮只修改协作仓库 `stonefish_slam_ws`。前一轮解决了部署与循环依赖，
但 app 仍承担本应由 UI、定位、仿真和 Guard 自己维护的实现。

实施范围：

1. `localization/` 接管 ORB 标定配置、RTAB 参数与地图文件检查；接口使用明确
   的参数和路径，不接收 app 的完整配置或包查找回调。
2. `ui/` 接管 X11 窗口和 RViz 布局；没有控制权或算法依赖。
3. `simulations/` 接管 survey 场景变换与光学，`guard/` 接管路线安全包络。
4. `robot/` 提供通用四元数转换和独立视觉模型；benchmark 不再为了坐标转换
   依赖控制器实现。
5. `app/` 保留配置校验、组装和生命周期；M2/M3 共用已安装 Python 组装模块，
   launch 文件只作入口，不按兄弟文件名动态加载实现。
6. 增加包含 launch 的依赖边界检查、生成配置的行为回归；完成容器构建、
   全部契约测试、M0 图形运行和 ORB 在线短程回归后发布。

不改增益、动力学、授权协议、DDS 或上游补丁。历史报告与源工作区保持原样。
本轮回归不能冒充全部 M1/M2/M3 正式重新验收。
